شو بيشغّل التطبيق من ورا

الموقع وتطبيق الموبايل بيشتغلوا على نفس قاعدة البيانات، لهيك الحساب والسلة والطلبات نفسها بالمكانين.

Firebase Authentication
تسجيل الدخول برقم الموبايل ورمز SMS، أو بحساب Google.
Cloud Firestore
قاعدة البيانات: المنتجات، الماركات، المستخدمين، السلة، المفضلة، والطلبات.
Cloud Storage
صور المنتجات ولوغوهات الماركات.
Cloud Messaging
الإشعارات للزبون والأدمن، وإشعارات العروض لكل المستخدمين.
Cloud Functions
بتبعت الإشعارات تلقائياً لما تتغير حالة الطلب، وبتحسب المجموع النهائي بأمان.
