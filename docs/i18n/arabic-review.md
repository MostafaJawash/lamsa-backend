# مراجعة النصوص العربية

يوثّق هذا الملف 111 موضعًا نصيًا أُضيف أو تغيّر ضمن تحويل نصوص الخادم وبياناته التجريبية إلى العربية الفصحى الحديثة. لا تشمل الحصيلة تحديثات الاختبارات المطابقة.

## Password validation

المصدر: `app/core/security.py`

| السابق | الجديد |
|---|---|
| كلمة المرور يجب ألا تزيد عن {PASSWORD_MAX_LENGTH} حرفاً. | يجب ألا تتجاوز كلمة المرور {PASSWORD_MAX_LENGTH} حرفًا. |
| كلمة المرور يجب ألا تكون أرقاماً فقط. | يجب ألا تتكون كلمة المرور من أرقام فقط. |
| كلمة المرور يجب ألا تكون رقم الهاتف. | يجب ألا تكون كلمة المرور رقم الهاتف. |
